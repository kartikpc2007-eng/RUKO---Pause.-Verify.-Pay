# RUKO frontend (React + Vite + Tailwind)
    npm install
    npm run dev      # http://localhost:5173  (backend must run on :8000)

## 2-minute demo
1. Scenarios -> 5 Normal Kirana Payment: green "Looks safe", Proceed.
2. Scenario 1 Fake Refund: meter, reasons, 10s pause, toggle हिन्दी, Read aloud, Alert Mom, Cancel Payment.
3. Scenario 2 KYC Lookalike: name mismatch + reported + new ID.
4. Scenario 4 Electricity message: highlighted phrases.
5. Safety Dashboard: money saved count-up, scams by type.
(Or press "Demo Mode" to auto-play all 5.)
